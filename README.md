# FlowPilot

AI-powered workflow management platform for cleaning businesses.

## 📖 What is FlowPilot?

FlowPilot automates the workflow of a cleaning business:

**Customer enquiry → AI extraction → structured data → deterministic pricing → quote → quote acceptance → booking → dashboard**

## 🏗️ Architecture

- **Frontend:** React + TypeScript (planned)
- **Backend:** Java 17 + Spring Boot
- **Database:** PostgreSQL 18
- **AI:** LLM API for natural-language extraction (planned)
- **Tools:** Maven, Git, Docker (planned)
